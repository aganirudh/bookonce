## Color Scheme

### Pricing
- Regular price: Blue (#3B82F6)
- Discount: Green (#10B981)
- Total: Bold black (#111827)

### Alerts
- Group dining: Orange (#F97316)
- Accommodation: Blue (#3B82F6)
- Tips: Gray (#6B7280)

### Status
- Available: Green (#10B981)
- Info: Blue (#3B82F6)
- Warning: Orange (#F97316)

## Interactive Elements

### Hover States
- Segment cards: Light gray background
- Pricing: Underline
- Tips: Slight scale up

### Click Actions
- Segment: Expand details
- Pricing: Show breakdown
- Tips: Show more info

## Responsive Breakpoints

### Desktop (1024px+)
- Two-column layout
- Full pricing sidebar
- All details visible

### Tablet (768px-1023px)
- Collapsible sidebar
- Compact segments
- Scrollable content

### Mobile (<768px)
- Single column
- Sticky pricing summary
- Expandable sections
